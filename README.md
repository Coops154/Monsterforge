# Monsterforge — Fusion Workshop (Sprint 1)

A browser-based fantasy card-fusion authoring tool, with tabletop and alchemist's sketchbook styling.

## Play
Once GitHub Pages is enabled, open: https://coops154.github.io/Monsterforge/

The prototype is a standalone `index.html` file. You can also download it and open it locally in a desktop browser.

## Features
- Sample card catalogue and card searching/filtering
- Combine 2–5 ingredient cards of **any** card types, including duplicates
- Exact recipes, such as 2 × Ogre + Rat → Rat Ogre
- Manual creation and approval of experimental card concepts
- Local persistence and JSON import/export for backups

## Enable GitHub Pages
1. In this repository go to **Settings → General → Danger Zone** and change visibility to **Public** if you are on a free GitHub plan (currently this repo was created private).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main**, then **/(root)**, and select **Save**.
5. After publication completes, open https://coops154.github.io/Monsterforge/ on your phone or computer.

## Notes
This is a Sprint 1 prototype, not the full settlement-defence game. Browser-local saves do not sync between devices. Export your card data as JSON regularly before clearing browser storage.
